FENDY RESEARCH LIBRARY
Pemilik: apt. Fendy Prasetyawan, S.Farm., M.Farm.

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka index.html di browser modern (Chrome/Edge/Firefox).
3. Pada penggunaan pertama, aplikasi memuat 176 catatan publikasi dari Excel sumber.
4. Data perubahan disimpan secara lokal pada browser/perangkat yang digunakan.
5. Buka menu Data & Cadangan, lalu pilih Ekspor cadangan JSON secara berkala.

FITUR
- 176 publikasi dari sheet 2021–2026 diimpor ke aplikasi.
- Pencarian dan filter tahun/status.
- Saran tema, subtema, dan metode berdasarkan judul; dapat dikoreksi pada detail artikel.
- Status membaca, prioritas, catatan telaah terstruktur.
- Sitasi APA 7: sitasi asli dari Excel ditampilkan jika tersedia; untuk referensi baru, lengkapi metadata penulis/jurnal/volume/issue/halaman/DOI. Verifikasi dengan artikel asli.
- Buka tautan jurnal dan pilih PDF lokal untuk membuka di tab browser.
- Ekspor cadangan JSON dan CSV, pulihkan JSON.
- Tampilan responsif Android dan laptop serta mode gelap.

BATASAN PENTING
- Aplikasi ini offline-first dan tidak mengirim data ke server. Situs jurnal tetap membutuhkan internet.
- Data disimpan di browser lokal. Jika menggunakan browser/perangkat berbeda, data tidak otomatis sinkron.
- File PDF yang dipilih tidak disimpan permanen oleh aplikasi dan tidak disertakan dalam cadangan JSON. Simpan PDF asli di folder perangkat Anda.
- Sitasi APA 7 tidak boleh dianggap final bila metadata penulis atau detail jurnal belum diverifikasi.
- Klasifikasi tema dibuat dari kata kunci judul; ini saran otomatis, bukan analisis isi penuh.
